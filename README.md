## .nvm_selector_barshrc

#### Install:

```shell
curl https://raw.githubusercontent.com/kritish-dhaubanjar/nvm-selector/refs/heads/main/.nvm_selector_bashrc -o ~/.nvm_selector_bashrc
```

```shell
echo "source $HOME/.nvm_selector_bashrc" | tee -a ~/.bashrc
```

```shell
source ~/.bashrc
```
